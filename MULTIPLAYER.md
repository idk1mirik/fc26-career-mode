# Мультиплеер: настройка (фазы 0–1)

1. Включи анонимный вход в Supabase Auth (Anonymous sign-ins).
2. Выполни `sql/001_multiplayer_rooms.sql` в SQL-редакторе Supabase. Скрипт можно запускать повторно.
3. Возьми service role ключ проекта Supabase и добавь его как `SUPABASE_SERVICE_ROLE_KEY`:
   - локально в `.env.local`;
   - в переменные окружения проекта на Vercel.
   Это серверный ключ: без префикса `NEXT_PUBLIC_`, в клиентский код и в git он не попадает.
4. Перезапусти dev-сервер и сделай redeploy на Vercel.
5. Проверка: открой `/multiplayer`, введи ник, создай комнату; во второй вкладке (лучше в режиме инкогнито) открой `/multiplayer/КОД` и войди с другим ником.

## Что уже работает
- Создание комнаты, вход по коду, уникальный ник в комнате.
- Выбор лиги хостом: лигу с числом клубов меньше числа игроков взять нельзя.
- Выбор клуба (один клуб — один игрок), готовность, исключение игрока, передача роли хоста.
- Чат с системными событиями, статус «в сети» (Presence), обновление в реальном времени с резервным опросом.
- Старт сезона хостом.

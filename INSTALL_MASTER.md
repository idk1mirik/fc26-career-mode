## Главная находка этого захода — баг рынка трансферов

Ты был прав, а мои прошлые объяснения про контракты были промахом мимо
цели. Реальная причина "не могу найти на рынке никого ниже 84":

`app/api/transfers/market/route.ts` без фильтра по лиге отдавал ВСЕХ
16000+ игроков игры, сортировал по рейтингу по убыванию и обрезал до
топ-100 (`.slice(0, 100)`). Игроков с рейтингом 84+ в игре хватает,
чтобы заполнить эти 100 мест целиком одной глобальной элитой — игрок с
рейтингом, скажем, 70, физически не мог попасть в список, если не сузить
поиск до конкретной лиги.

Исправил: если поиск/лига уже сужают пул (обычный сценарий) — не режем
по рейтингу вообще, отдаём до 300 подряд. Если фильтров нет вообще (весь
рынок разом) — берём РАЗНООБРАЗНУЮ выборку по стратам рейтинга (по 30 из
каждого диапазона 0-59/60-69/70-77/78-84/85-99), а не топ по одному
критерию.

## Логотипы (Ł/ł) — теперь во ВСЕХ трёх копиях сразу

Прошлый раз я нашёл и исправил баг с польской буквой Ł в двух местах, но
только в отдельной проверочной копии проекта — она не попала в общий
пакет. Сейчас перенёс фикс во все 3 места разом: `data/clublogos.ts`,
`lib/normalize.ts`, `utils/slugify.ts` (последняя не используется нигде,
но на всякий случай тоже поправил).

## Контракты/свободные агенты — для справки, что реально было сделано

Формула длительности контракта (`lib/contracts.ts`) была изменена так,
чтобы игроки любого возраста могли получить короткий контракт — не только
возрастные. Но важно понимать: это работает только для НОВЫХ контрактов.
Для уже идущей карьеры контракты были созданы один раз в начале и просто
тикают вниз по старой формуле — формула сама по себе их не переделает.
Если пул свободных агентов в твоей ТЕКУЩЕЙ карьере всё ещё однобокий —
это ожидаемо, и это отдельная, не сделанная пока задача (нужен инструмент
"пересчитать длительности существующих контрактов"), скажи, если она
всё ещё актуальна с учётом того, что баг рынка (видимо, основная путаница)
теперь исправлен.
